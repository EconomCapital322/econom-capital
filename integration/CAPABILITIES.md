# Реестр возможностей «Спектра»

Исходная версия общего проекта — `9da4d38` с локальной полировкой интерфейса команды 3. Реестр составлен до объединения по модулям, публичному API, экранам и тестам. Колонка «В общем интерфейсе» задаёт маршрут проверки. Команды в колонке «Проверка» относятся к проверкам, описанным в итоговом отчёте.

| Модуль и возможность | До объединения | В общем интерфейсе | Проверка |

| 1. Расчёт C++ по договору, типы графиков и ставок, пересмотры, досрочные платежи и субсидии | `calculator/cf`, `cfcore` | Портфель → Конструктор → расчёт, результаты в «Составе портфеля». Полный набор входов по-прежнему доступен через CLI | CTest, pipeline |
| 1. Отчёты, банковская сверка Excel, CLI и параллельный расчёт | Отдельные выгрузки и тесты ядра | Состав портфеля → вход и результаты. Исходные отчёты CLI сохраняются | CTest, тест Excel, экспорт |
