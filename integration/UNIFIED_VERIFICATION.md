# Проверка объединённого «Спектра»

## Архитектура и изменения

`make spectrum-up` поднимает PostgreSQL, миграции, API и worker кривых, Go stress и «Спектр». Go base-curve входит в backend модуля кривых. Аналитический контейнер включает C++ калькулятор и сборку React. На порту 8780 доступны все пять разделов.

React встроен в существующую оболочку как модуль с одним корнем. Приложение переиспользует исходные компоненты, хуки и API-адаптер. Стили находятся в Shadow DOM, а диалоги и выбор дат используют тот же корень. Адрес с датой, Run ID или сохранённым снимком восстанавливает нужный экран при обновлении. Выделенный origin второго модуля доступен в его самостоятельном запуске. [Реестр возможностей до и после](CAPABILITIES.md)

## Контрольный сценарий на рыночных данных

Параметры генерации: 120 сделок на старте, 16 новых в месяц, семь дат по 30.10.2026, seed `4317`. Договоры синтетические. Worker в новой БД заново получил ставки MOEX и построил семь кривых на каждую дату. При первой попытке TLS-ошибка отобразилась как недоступность источника. После добавления доверенного сертификата worker завершил обработку.

В интеграционном интерфейсе проверены исходные ставки, сравнение кривых, пользовательский перерасчёт и история. У выбранной даты свой Run ID. Применённые кривые связаны с отчётом по идентификаторам и контрольным суммам. Многодневная история рассчитывается из CF C++, а сохранённый снимок открывается отдельно от текущего состояния API.

## Методология и границы проверки

Разложение Шепли для CF и DF использует четыре состояния, разницу входа/выхода сделок и проверку с выгрузкой. Проверки независимого CSV, временной валидации, нелинейностей, пар, остатка, вывода и подмены провайдера перечислены в [таблице соответствия](../factor-analysis/docs/specification-matrix.md).

Пользовательские сценарии хранятся в модуле кривых. Финансовый конвейер использует готовые стандартные кривые с 23 бакетами. Отчёты на прежних снимках остаются доступны после переоценки. Веб-интерфейс принимает готовые нормализованные снимки с потоками и кривыми. Для произвольного исходного банковского CSV и ручного JSON служит CLI калькулятора.

Финальная проверка на банковской истории ждёт обезличенный многопериодный набор и эталонные оценки. Полная методика EC и NII открыта. В текущем прогоне AI проверен на локальных фактах и ответах тестового провайдера. Нативные Windows-скрипты сохранены. Локальный браузерный прогон выполнен на macOS, серверный стек проверен в Linux-контейнерах. Расширенная проверка взаимодействий при переобучении и автоматическое сравнение нескольких соседних интервалов остаются вне этой итерации.
