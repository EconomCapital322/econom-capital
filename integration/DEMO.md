# Демонстрация трёх команд

Откройте [Спектр](http://127.0.0.1:8780/) после `make spectrum-up`. Сценарий рассчитан примерно на девять минут и проходит в одной вкладке. Перед встречей подготовьте рыночные даты контрольного портфеля и один раз выполните сквозной расчёт. В холодном запуске загрузка ставок и работа очереди зависят от источника.

| 0:00–0:40 | Коротко пройти верхнюю навигацию | Команда 1 строит расписание платежей, команда 2 рассчитывает кривые, команда 3 соединяет результаты и исследует изменение метрики. |
| 0:40–2:00 | **Кривые**, 30.10.2026 | Источник MOEX, базовая кривая, сравнение двух стрессов, исходные ставки, таблица. В **Параметрах** показать P, K и D. В **Истории** выбрать готовый стандартный запуск. |

Запуск за 30.10 закреплён, на остальные даты загружаются свои стандартные кривые. На экране отображаются стадии получения кривых, C++ и дисконтирования. |

Для итогового EC, полного NII и банковской валидации нужны согласованные определения и обезличенная история. |

## Резерв без MOEX

1. До встречи скачайте ZIP снимков из **Данные → Источники расчёта**. Выгрузите отчёт NPV в JSON и автономный HTML.
2. При недоступности API загрузите ZIP. Скажите, что это сохранённый расчёт. В **Сценариях** ссылка на применённые кривые откроет архивный график без запроса к API команды 2. Отдельный учебный режим портфеля подписывает синтетические кривые.
3. Для ML скачайте [учебный CSV](../factor-analysis/examples/analysis.csv). Пример содержит числовые и категориальные признаки. Для проверки независимости от заголовков замените первую строку на `week_end,case_key,outcome_score,shipment_volume,route_shift,service_band`, затем сопоставьте первые три колонки.
4. Откройте сохранённый HTML ML-отчёта, если времени на расчёт нет. Для живого вопроса используйте режим объяснения по фактам. Он доступен и при отключённом DeepSeek.

После ML для возврата к расчётному режиму импортируйте ZIP заново. Архив сохраняет дату, Run ID и SHA-256 каждого рыночного снимка. [Общий запуск](../README.md#единый-запуск)
