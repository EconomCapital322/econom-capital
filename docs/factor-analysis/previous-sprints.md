# Факторный анализ в спринтах 1 и 2

Краткое описание методики и результатов команды «Теневое правительство». Расчётные материалы и презентации доступны по ссылкам на версии проекта, использованные для сдачи.

## Спринт 1. Денежные потоки одной сделки

Воспроизвели 334 платежа по сделке с датой оценки 31.08.2022 и остатком долга 3 646 037,89 руб. Начисление процентов рассчитали по фактическим дням ACT/365F. Сравнили аннуитет (ANN), равномерное погашение основного долга (RGM) и погашение основного долга в конце срока (SIMPLE).

| График | Проценты, руб. | Приведённая стоимость платежей, руб. |
| --- | ---: | ---: |
| ANN | 5 039 033,17 | 3 646 037,92 |
| RGM | 3 812 984,12 | 3 646 037,90 |
| SIMPLE | 7 604 236,54 | 3 646 037,88 |

В эталонном примере кредитная и дисконтная ставки равнялись 7,5%, поэтому приведённые стоимости близки к остатку тела. Разница между графиками видна в сроках возврата тела и суммах процентов. Прототип зафиксировал формулы, формат входа и проверки для сверки с калькулятором. ## Спринт 2. Чувствительность к параметрам и дисконтированию

Выполнили 19 расчётов на одной сделке. Меняли по одному параметру — сумму долга, договорную ставку, оставшийся срок, уровень ставок дисконтирования или способ получения дисконт-фактора. В каждом расчёте сравнивали базовый и стрессовый сценарии для одного графика. При сравнении способов получения DF платежи сохранялись одинаковыми.

| Метод получения DF | Снижение стоимости в стрессовом сценарии, тыс. руб. |
| --- | ---: |
| Готовый DF интервала | 164,7 |
| Линейная интерполяция DF | 170,9 |
| Линейная интерполяция нулевых ставок | 167,6 |

На длинных сроках важен расчётный тенор из источника. У узла с подписью `30y` в файле был задан тенор 25 лет. Интерполяция использует 25 лет, а расчёт после крайнего узла зависит от выбранного правила. При сдвиге обеих кривых на +200 б. п. обе оценки упали. Разница «стресс минус база» изменилась примерно с −164,7 тыс. до −127,6 тыс. руб. ## Связь со спринтом 3

В «Спектре» результаты одного графика используются для оценки портфеля по кривым. Договорные CF выдаёт общий калькулятор, кривые — модуль кривых, «Спектр» соединяет их по отчётной дате и рассчитывает PV и изменение к базе. Модельное разложение Шепли для синтетического портфеля открывается на отдельном экране программы. [Описание и запуск «Спектра»](../../factor-analysis/)
