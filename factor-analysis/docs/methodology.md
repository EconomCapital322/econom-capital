# Методология факторного анализа «Спектра»

Постановка задаёт наблюдаемый результат, например NPV, и просит объяснить, почему он меняется между двумя датами. Классический статистический факторный анализ описывает скрытые переменные по структуре зависимостей между признаками. Для задачи с явной целевой метрикой «Спектр» использует нелинейную регрессию и атрибуцию её предсказаний. [Работа об общей факторной модели](https://pmc.ncbi.nlm.nih.gov/articles/PMC9433369/) · [Lundberg и Lee, SHAP](https://papers.nips.cc/paper_files/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html)

## Как получаются значения для анализа

1. Генератор формирует сделки с воспроизводимым кодом. На следующую дату остаток уменьшается на погашения из выхода C++-ядра. Можно задать число новых сделок на дату. Все исходные сделки синтетические.
2. «Спектр» передаёт нормализованный CSV ядру команды 1. Пропуски и ошибки расчёта останавливают публикацию новой рабочей версии. Ставки по плавающим синтетическим сделкам используют заданный тестовый индекс и договорную надбавку.
3. На ту же дату «Спектр» запрашивает у команды 2 стандартный комплект из семи рыночных кривых. Бакет и DF для каждого платежа определяет общий модуль дисконтирования. Стоимость по сценарию равна сумме PV платежей, а отклонение равно стоимости сценария минус стоимость по базе. [Контракт команды 1 и 2](../../integration/CONTRACT.md)
4. Анализ работает на таблице «сделка × дата». Встроенные цели включают NPV базы, ΔPV выбранного стресса, проценты и полные договорные платежи за ближайшие 12 месяцев. В своём CSV можно указать другую числовую метрику. Она должна иметь смысл при суммировании по наблюдениям.

## Факторы и вклады

Профиль показывает типы колонок, пропуски, уникальность и числовые диапазоны. При загрузке своей таблицы кандидаты определяются по содержимому колонок. Константы, даты, идентификаторы, признаки с пропусками более 50% и категориальные поля с более чем 30 уровнями исключаются из кандидатов. Пользователь может скорректировать список перед расчётом. Для встроенного набора кандидаты берутся из контрактных параметров и кривых. Колонки со сценарными результатами защищены от попадания в признаки.

Модель — случайный лес с фиксированным seed. Заполнение пропусков и кодирование категорий настроены по обучающему периоду. Колонки one-hot после расчёта вклада объединяются обратно в исходный признак. Локальные SHAP-вклады вычисляются для общих сделок на обе даты, затем складываются разности этих вкладов по сделкам. Модель для разложения обучается на датах строго раньше начала сравнения. [TreeSHAP и взаимодействия](https://www.nature.com/articles/s42256-019-0138-9)

Наблюдаемое изменение равно сумме четырёх частей.

- Значения по ID, появившимся на конечную дату.
- Минус значения по ID, которые есть только на начальную дату.
- Модельные вклады по общим ID.
- Необъяснённый остаток по общим ID, то есть наблюдаемая разница минус разница предсказаний.

При импорте своей истории проверьте полноту снимков, иначе исчезновение строки будет трактоваться как выбытие ID. Интервал рядом с вкладом отражает полосу между 10-м и 90-м процентилями 100 повторных выборок общих сделок из выбранного сравнения. Он показывает чувствительность к составу сделок и не интерпретируется как доверительный интервал будущего периода.

## Глобальные эффекты и проверка

- **Важность.** Для каждой проверочной даты случайно переставляем значения группы колонок одного признака и измеряем повышение MAE. В интерфейсе видны средний, минимальный и максимальный результаты по датам. Константные внутри даты ставки не ранжируются по этой оценке. Для всех обученных признаков дополнительно показан средний модуль SHAP по общим сделкам на конечную дату. Зависимые признаки могут делить важность. [Fisher, Rudin и Dominici, важность переменных](https://www.jmlr.org/papers/v20/18-760.html)
- **Взаимодействия.** Тепловая карта показывает средний абсолютный попарный вклад TreeSHAP на конечную дату. Для ограниченного времени вычисления берётся воспроизводимая случайная выборка до 180 общих ID без повторений. Симметричные половины одного попарного эффекта складываются. Вклады взаимодействий уже входят в факторный водопад. [Lundberg и соавторы, локальные взаимодействия](https://www.nature.com/articles/s42256-019-0138-9)
- **Нелинейность.** График ALE показывает накопленный локальный эффект признака по диапазонам с наблюдениями. В конце он центрируется относительно выборки. Для категорий показывается средний SHAP по уровню с числом строк. [Apley и Zhu, Accumulated Local Effects](https://arxiv.org/abs/1612.08468)
- **Устойчивость.** На нескольких поздних датах сравниваются MAE случайного леса, линейной модели Ridge и медианы прошлых наблюдений. Каждый прогон учится только на предыдущих датах. Слабое качество, большой остаток или нехватка данных показываются в интерфейсе. Проверка оценивает перенос на более поздние снимки портфеля. Для исследования переноса на другой банк или портфель нужны отдельные данные. [Проверка временного ряда с последовательным переносом точки отсечения](https://otexts.com/fpp3/tscv.html)

## Объяснение и область применения

LLM получает названия фактов и вопрос пользователя. Она выбирает идентификаторы, а текст и числа подставляются из текущего отчёта после проверки. Источники ведут к графику, взаимодействиям или проверке модели. При недоступной модели предусмотрен ответ по подтверждённым фактам.

Вклады показывают связи, обнаруженные моделью. Для причинного вывода нужна дополнительная проверка гипотез. Изменение PV и проценты за 12 месяцев отражают риск и график по входным инструментам в рамках проекта. Итоговый Economic Capital, NII с фондированием и прогнозом баланса, а также валидация на закрытых банковских данных остаются за пределами текущих расчётов.
