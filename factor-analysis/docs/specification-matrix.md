# Соответствие постановке команды 3

Сверка выполнена с исходным документом «Постановка задачи. Часть 3. Факторный анализ Economic Capital». Используется точная финансовая декомпозиция для снимков калькулятора. Универсальный режим оценивает связи и атрибутирует модельную часть изменения произвольной суммируемой метрики.

| Требование | Алгоритм и файл | Место в интерфейсе | Проверка | Статус и границы |
| --- | --- | --- | --- | --- |

| Произвольная метрика, период и набор колонок | `service/panel.py`, `service/server.py`, сопоставление даты, ID и цели | Данные → Настройка, Анализ → Изменить параметры | Playwright с переименованными колонками | Проверено для суммируемой числовой цели. |
| Автоматический отбор, число и категории | `service/attribution.py`, `pick_features`, `Encoding` | Данные → Проверить структуру, выбор факторов | `test_temporal_training_excludes_both_comparison_dates_and_future_proxies`, `test_pair_and_category_and_correlation` | Проверено.
