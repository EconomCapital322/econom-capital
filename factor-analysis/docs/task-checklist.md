# Чек-лист доработки «Спектра»

Нумерация соответствует разделу 3 постановки. Последующие разделы постановки проверены отдельно ниже. Предыдущий этап включает изменения ветки до `f8b6890`. Эта итерация закрывает оставшиеся задачи, для которых доступны расчётные данные и контракты.

| --- | --- | --- |
| 1 | Числовые и категориальные признаки | Готово ранее. Тесты показывают отдельные эффекты категорий и числовое кодирование. |
| 2 | История за несколько периодов | Готово ранее. Генератор и импорт ZIP с несколькими датами проверены сквозным тестом. |
| 3 | Произвольная аддитивная числовая метрика | Готово ранее. Тестовый CSV с метрикой «стоимость» и пользовательской единицей. Среднее и коэффициенты требуют другой операции агрегации. |
| 4 | Автоматический отбор факторов | Готово ранее. Кандидаты ранжируются по обучающим датам. Тест включает признаки после 16-й колонки. |
| 5 | Произвольный набор признаков | Готово ранее. Можно выбирать и исключать неизвестные поля. Браузерный тест использует длинное пользовательское имя колонки. |
| 6 | Профилирование | Доработано. Типы, диапазоны, пропуски, выбросы и дубликаты. В форме дополнительно видны число уникальных ID и количество отобранных факторов для текущей настройки. |
| 7 | Нелинейность | Доработано. ALE, наблюдаемые вклады SHAP, ICE и PDP. Подстановки ограничены наблюдаемой областью и проверкой зависимости признаков. |
| 8 | Пороговые эффекты | Готово ранее. Проверка на обученной модели с искусственным порогом и достаточным числом наблюдений. |
| 9 | Насыщение | Готово ранее. Проверка на обученной модели с искусственным насыщением. |
| 10 | U-образные и перевёрнутые U-образные формы | Готово ранее. Проверены обе формы на известных функциях и обученных моделях. |
| 11 | Разные режимы поведения | Доработано. В таблице ALE показан локальный наклон. Форма проверяется повторной выборкой и переобучением. |
| 12 | Взаимодействия | Готово ранее. Есть парные вклады, интервалы и график, проверена известная пара из синтетической формулы. Из карточки фактора можно перейти к связанным парам. |
| 13 | Глобальная важность и локальный вклад | Доработано. Три показателя читаются отдельно, в том числе устойчивость рейтинга перестановочной важности между датами. |
| 14 | Количественное объяснение изменения | Доработано. База и все шесть стрессов сверяются с калькулятором. Внутри эффекта потоков видны плановые погашения, перенос по срокам и изменения проверенных условий. |
| 15 | Изменение состава портфеля | Доработано. Новые и выбывшие ID входят в водопад. Добавлены структура по сторонам, схемам и типам ставки, а также новые выдачи с известной датой. |
| 16 | Необъяснённый остаток | Готово ранее. Отдельные значения остатка ML и расчётной невязки. Тесты проверяют сверку и случай недостатка данных. |
| 17 | Устойчивость | Доработано. Временная проверка, bootstrap по общим ID, два seed переобучения, сравнение рангов, устойчивость знака, формы и взаимодействий. |
| 18 | Сравнение с базовыми методами | Доработано. Медиана, Ridge, Random Forest и Extra Trees. Для каждого временного фолда в JSON записаны параметры и метрики всех кандидатов. |

| 22 | Воспроизводимость | Готово ранее. Снимки компонентов, SHA-256 кривых, фиксированные зависимости и seed, параметры модели в отчёте. |
| 23 | Подтверждение на синтетике и реальных данных | Частично проверено. Синтетические формулы, договоры и реальные рыночные кривые MOEX проверены. Для серийной валидации на банковских сделках нужны обезличенные снимки на несколько дат и контрольные результаты банка. |
| 24 | Заменяемый LLM | Готово ранее. Одна схема для DeepSeek, локальной модели и режима проверенных фактов. Отдельная команда для проверки реального API добавлена в этой итерации. |
| 25 | Понятный отчёт с источниками | Доработано. JSON, CSV и автономный HTML, в том числе детализация потоков, источники, ограничения и проверенное объяснение. |

## Расчёт и эксплуатация

- [x] P0 и разделы 2, 4–6, 10, 14–15. Проверены общий контракт `calendar-bucket-v1`, разложение NPV и изменения стрессовой ΔPV, один расчёт модели на обе даты, обработка ошибочных данных и устаревших ответов. В общий CI включён факторный анализ.
- [x] Разделы 5.1 и 11. Контрфактические варианты остатка, ставки и связанной пары «срок и график» проходят через C++. Оба сохранённых графика сверяются по датам, типам и суммам. Недоступные сочетания остаются в общем вкладе. Проверен импорт совместимых снимков без повторного запуска C++ для переключения стресса.
- [x] Разделы 7–10. Проверены ручной выбор и отбор признаков по обучающим данным, поддержка графика эффекта, корреляции, взаимодействия и временная валидация. У рыночных факторов учитываются независимые даты.
- [x] Раздел 12. DeepSeek проверен на mock HTTP. В приложение передаются только проверенные формулировки, запрос провайдеру содержит обезличенные ID фактов. Офлайн-режим выдаёт ответ при недоступности AI.
- [x] Реальный вызов DeepSeek. Модель `deepseek-flash` через `/api/explain` вернула проверенный план по погашениям на синтетическом портфеле. Отдельную проверку можно запустить командой `python -m service.deepseek_smoke --live`.
- [x] Раздел 13. Сохранены четыре раздела интерфейса. Есть интерактивный водопад, таблицы, графики, переходы к источникам и прогресс по стадиям. Браузерная проверка охватывает пять размеров экрана, клавиатуру, импорт и выгрузки.
- [x] Разделы 16–18. Обновлены запуск, примеры, формулы, настройки AI, CSV/JSON/HTML и измерения производительности. Длительная детализация запускается отдельно, с ограничениями по выборке и числу пересчётов.
- [x] Разделы 19–21. Результаты и доступные проверки отражены в отчёте, методике и памятке по запуску. Критерии приёмки, требующие внешних данных или среды, перечислены ниже.

## Проверки с внешними зависимостями

- [ ] Валидация на банковском портфеле. Нужны несколько обезличенных исторических дат, те же даты кривых и контрольные значения. Учебный вход МАИ за одну дату отдельно проверен штатным калькулятором.
- [ ] Расчёт полного NII и итогового Economic Capital. Нужны банковские формулы и соответствующие входные данные. Доступны NPV, стрессовая ΔPV и договорные потоки за 12 месяцев.
- [ ] Проверка запуска на Windows/WSL. В документации приведён вариант с Linux-контейнерами. Набор проверок запускался на macOS и в контейнерах Linux.
- [ ] GitHub Actions для этой итерации. Локальные проверки приведены в отчёте. Общий workflow запускается при открытии PR в `main`.
