# «Спектр» · факторный анализ портфеля

«Спектр» отвечает на вопрос, почему изменилась стоимость портфеля между двумя датами. В **расчётном режиме** приложение сверяет договорные платежи и NPV с общим калькулятором и раскладывает изменение на потоки, дисконтирование и состав портфеля. В **ML-режиме** оно анализирует произвольную суммируемую метрику, оценивает вклад признаков и отдельно показывает необъяснённый остаток.

## Запуск на macOS и Linux

Нужен весь репозиторий `econom-capital`, включая `calculator` и `curves-module`. Для запуска на компьютере установите Python 3.11 или новее (проверено на 3.12), Node.js, CMake 3.20+, C++20, Make и Docker Compose 2.20+ для рыночного API. На macOS запустите Docker Desktop. На Linux включите Docker Engine.

```sh
cd factor-analysis
./start.command
```

Откройте браузер на порту 8780. На macOS можно также открыть `start.command` двойным щелчком. Скрипт создаёт `.venv`, сверяет версии библиотек, при необходимости собирает `cfcore` и запускает сервис кривых. Окно терминала держит приложение открытым. `Ctrl+C` останавливает «Спектр». Данные расчётов и Docker-стенд сохраняются. [Открыть «Спектр»](http://127.0.0.1:8780/)

- Если `python3` указывает на старую версию, задайте путь к установленному интерпретатору, например `SPECTRUM_PYTHON=python3.12 ./start.command`.
- Если сервис кривых уже доступен, просто откройте «Спектр». Для другого адреса укажите `SPECTRUM_CURVES_URL`. Если калькулятор собран отдельно, укажите путь `SPECTRUM_CFCORE`.
- Для запуска без Docker и MOEX используйте `SPECTRUM_SKIP_CURVES=1 SPECTRUM_LLM_ENABLED=0 ./start.command`. В **Портфеле** выберите **Учебные кривые (офлайн)**. Сборка ядра и первая установка зависимостей могут потребовать интернет.
- Для расчёта по сохранённым ответам команды 2 выберите **Сохранённые рыночные кривые**. На каждую дату нужен полный официальный снимок `factor-analysis/.local/curves/YYYY-MM-DD.json`. При наличии готового портфеля можно открыть его сразу.

### Запуск через Docker

Из корня репозитория выполните следующие команды. Compose поднимет API команды 2 и «Спектр» с собранным `cfcore`. Для браузера используются обычный адрес «Спектра» 8780 и интерфейс кривых 5173. Если уже запущен другой локальный экземпляр на этих портах, сначала используйте свободные порты или завершите свой предыдущий запуск.

```sh
make configure
docker compose -f docker-compose.yaml -f factor-analysis/compose.yaml up -d --build
```

Данные сохраняются в томе `spectrum_data`. Порт «Спектра» в Compose можно изменить через `SPECTRUM_DOCKER_PORT`. Для расчёта по учебным кривым достаточно отдельно собранного образа «Спектра». На Windows используйте Docker Desktop с Linux-контейнерами и WSL 2 для `make configure` и команд запуска. Нативный `.command` в Windows и запуск на WSL не тестировались.

При ошибке TLS в worker MOEX сохраните официальный сертификат в `factor-analysis/.local/certs/moex-ca.pem` либо задайте `SPECTRUM_MOEX_CA`. Для уже поднятого стенда добавьте `-f factor-analysis/compose.moex-ca.yaml` к файлам Compose и пересоздайте `worker`. Для обработки новых дат API и worker должны использовать `AUTOMATION__ENABLED=true` из `curves-module/.env`. Затем повторите подготовку проблемной даты в интерфейсе команды 2. При отсутствии публикации за дату выберите доступную отчётную дату. [Инструкция MOEX](https://www.moex.com/n106155?nt=112)

## Сквозной показ

1. **Портфель → Рассчитать портфель.** По умолчанию 120 исходных сделок, 16 новых в месяц и семь дат с 30 апреля по 30 октября 2026 года. Для автономного показа выберите учебные кривые. Состав по каждой дате загружается отдельно. Нажмите на ID, чтобы открыть график калькулятора. Долю обязательств и код воспроизведения можно менять в расширенных параметрах.
2. **Факторный анализ → Расчётный → NPV базы.** Для примера выберите 30 сентября и 30 октября. На водопаде есть новые и выбывшие сделки, денежные потоки, дисконтирование и расчётная невязка. В **Деталях расчёта** видны четыре комбинации потоков и кривых, совместный эффект и таблица по срокам платежей.
3. **Сценарии ставок.** Выберите стресс и дату, сравните стоимость по базовой и стрессовой кривым. `ΔPV = PV стресса − PV базы` измеряется на одну дату. Кнопка **Объяснить изменение сценария** открывает настройки сравнения ΔPV между датами. Переключение использует сохранённые снимки.
4. **Факторный анализ → Универсальный ML.** Выберите показатель и нажмите **Разложить изменение**. В **Проверке модели** откройте ошибки на обеих датах. В **Нелинейных эффектах** или **Взаимодействиях** нажмите **Рассчитать детализацию**. Длительная диагностика выполняется по запросу после основного разложения.
5. **Данные → Источники расчёта.** Откройте исходные кривые, платежи и PV на одну дату. На графике **Объяснение** можно спросить «Как повлияло изменение кривой?» или «Насколько надёжен результат?». Источники ведут к соответствующим деталям.

## Свои данные и экспорт

- **CSV для ML.** Откройте **Данные → Загрузить таблицу CSV**. Поддерживаются UTF-8, разделители `,`, `;`, табуляция, до 6 МБ, 20 000 строк и 80 колонок. Нужны уникальная пара «ID и дата», аддитивная числовая метрика и признаки. Выберите поля, даты и единицу измерения, проверьте колонки и нажмите **Рассчитать ML-вклады**. Кандидаты видны целиком, отбор до 16 факторов проводится только по обучающему периоду. [Учебный CSV с нелинейностью и взаимодействием](examples/analysis.csv)
- **ZIP для расчёта.** В **Данных** можно скачать историю текущего портфеля и загрузить её на другом стенде. Для вручную собранного архива в корне должны лежать папки `YYYY-MM-DD`, по одной на каждый снимок. Импорт поддерживает от 2 до 12 дат, 16 МБ архивированного и 96 МБ распакованного содержимого. Дополнительные поля исходного банковского файла сначала приводятся к [нормализованной схеме команды 1](../calculator/cf-normalizer/contracts/normalized-deals-v1.json).

```text
YYYY-MM-DD/
├── calculator_input.csv
├── core/
│   ├── cashflows.csv
│   ├── deal_summary.csv
│   └── discounted_deal_summary.csv
└── curves/standard-result.json
```

Для архива, экспортированного «Спектром», проверяется также `manifest.json` с датами, ID расчётов и SHA-256 кривых. Если дата, валюта, сторона, ID или стоимость расходятся, импорт выдаёт сообщение и оставляет последний готовый отчёт доступным. При неполном снимке пропавший ID учитывается как выбытие, поэтому проверьте состав выборки.

- **Экспорт** над факторным анализом скачивает JSON текущей ревизии и CSV вкладов. После детализации доступен CSV взаимодействий, в режиме ML — CSV качества. В JSON сохраняются настройки, источники, ограничения и проверенное резюме, если пользователь его запросил. В CSV текстовые значения обрабатываются для открытия в электронных таблицах. Локальные снимки лежат в `factor-analysis/.local/runs/`.

## Объяснения и DeepSeek

Без AI приложение объясняет результат из проверенных фактов. Это режим по умолчанию в `.env.example`. Для подключения DeepSeek скопируйте `factor-analysis/.env.example` в `factor-analysis/.env` или `.env.local`, задайте поля ниже и перезапустите приложение. Ключ вводится в локальном файле с ограниченными правами или через защищённые переменные окружения. Для Compose используйте переменные процесса запуска.

```dotenv
SPECTRUM_LLM_PROVIDER=deepseek
SPECTRUM_ALLOW_EXTERNAL_LLM=true
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_API_KEY=
```

Сервер принимает только официальный HTTPS-хост DeepSeek. Во внешний запрос уходят режим и обезличенные идентификаторы фактов. Исходные тексты вопросов, колонки, банковские строки, даты и суммы остаются локально. Для загруженных наборов нужно отдельное разрешение в форме вопроса. DeepSeek собирает структуру объяснения, а сервер проверяет ответ и подставляет фактические числа, ссылки и ограничения. При ошибке используется объяснение по фактам. [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) · [Модели DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)

Для доступной локальной модели укажите `SPECTRUM_LLM_PROVIDER=local`, `SPECTRUM_LLM_URL` и `SPECTRUM_LLM_MODEL`. На Apple Silicon `start.command` может запустить подготовленный `mlx-lm` из `.local/llm`. Сохраните `SPECTRUM_LLM_ENABLED=0` для запуска с проверенными фактами без обращения к модели.

```sh
# Из корня econom-capital после установки зависимостей запуска
make check-factor-analysis
```

Для полного NII и Economic Capital требуется банковская методика и соответствующие данные. Проверки на внутренних банковских данных требуют отдельной обезличенной истории.
