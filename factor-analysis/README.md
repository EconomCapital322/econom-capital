# «Спектр» для анализа портфеля

«Спектр» формирует историю синтетических сделок, запускает ядро C++ команды 1, получает рыночные кривые команды 2 и анализирует изменение показателя портфеля между двумя датами. Результаты привязаны к отчётным датам и идентификаторам запусков кривых.

## Запуск на этом компьютере

Откройте `start.command` двойным щелчком или запустите его из терминала. Интерфейс откроется на [127.0.0.1:8780](http://127.0.0.1:8780/). Окно терминала держит сервер открытым. Если он уже работает, скрипт откроет страницу без второго процесса.

Для первой установки нужны Docker Desktop, Docker Compose, Node.js, Python 3.11 или новее, CMake и компилятор C++20. Скрипт использует локальные зависимости, создаёт Python-окружение при необходимости и проверяет API кривых. Адрес существующего API меняется через `SPECTRUM_CURVES_URL`. Если бинарник команды 1 собран в другом месте, задайте `SPECTRUM_CFCORE`.

### Локальная модель объяснений

На компьютере с Apple Silicon локальный Qwen доступен через MLX. Для чистой установки выполните из папки `factor-analysis`:

```sh
python3 -m venv .local/llm
.local/llm/bin/python -m pip install mlx-lm==0.32.2
./start.command
```

Первый запуск MLX загрузит модель. Можно использовать другой локальный сервер с API chat completions через `SPECTRUM_LLM_URL` и `SPECTRUM_LLM_MODEL`. В резервном режиме интерфейс отвечает фактами из вычисленного отчёта. Исходные сделки и значения целевой метрики не отправляются языковой модели.

### Кривые и TLS

Калькулятор и «Спектр» читают публичный API модуля команды 2. При необходимости положите сертификат из официального источника в `.local/certs/moex-ca.pem` или укажите абсолютный путь через `SPECTRUM_MOEX_CA`. Compose использует сертификат только в worker кривых. Системное хранилище не затрагивается. [Инструкция Московской биржи](https://www.moex.com/n106155?nt=112)

При отключении MOEX можно открыть последний рассчитанный портфель. Повторный расчёт допускает использование полного сохранённого рыночного ответа на каждую выбранную дату. Источник всегда виден в «Данных».

## Сценарий показа

1. **Факторный анализ.** Выберите период и метрику. На водопаде видны фактическая разница, новые и выбывшие сделки, модельные вклады и остаток. Нажмите на «Остаток долга» для сравнения значений. Откройте «Взаимодействия» и «Проверка модели».
2. **Сценарии ставок.** Выберите дату. Сверху указано число сделок во всей выгрузке. Нажмите на стресс или выберите его в списке. Интерфейс покажет изменение PV и его разложение по срокам платежей, базовую и выбранную стрессовую кривые.
3. **Портфель.** Задайте число начальных и ежемесячных новых сделок, число дат и диапазоны договорных параметров. «Рассчитать портфель» запускает всю цепочку. В составе портфеля по ID открываются платежи из отчёта команды 1.
4. **Данные.** За каждую дату можно скачать вход калькулятора, полученные потоки и неизменённый ответ кривых. Свой CSV должен содержать одну строку на ID и дату, числовую целевую метрику и колонки потенциальных факторов.
5. **Объяснение.** Спросите, почему изменилась NPV или было ли сильное взаимодействие. В ответе появятся переходы к рассчитанным значениям. Языковая модель выбирает факты, числа берутся из расчёта.
