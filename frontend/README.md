# Economic Capital · Модуль кривых

Фронтенд команды 2 практики Т1. React + TypeScript + Vite, Bootstrap и TanStack Query. Шрифт Geologica 400/500/600/700 и изображения хедера подключены локально. Главная страница и окно параметров оформлены по SVG-макетам от 23.10.2026.

## Запуск

Нужен Node.js 20.19+ (ветка 20) или 22.12+ и npm.

Из папки `frontend`:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для локальной проверки сборки:

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm run preview
```

Сборка создаётся в `dist`. Приложение запускается через Vite/HTTP, не через открытие `index.html` как файла.

## Переменные окружения

При необходимости скопируйте `.env.example` в `.env.local`:

```dotenv
VITE_API_BASE_URL=
```

Это базовый адрес будущего API. Пока HTTP-контракта в репозитории нет, используется демонстрационный адаптер. Заполнение переменной **не включает реальные запросы**. Секреты в VITE_* не размещать: эти значения доступны браузеру. После изменения `.env.local` перезапустите Vite.

Порядок подключения сервера и недостающие сведения: [API_INTEGRATION.md](./API_INTEGRATION.md).

## Демонстрационный режим

- Исходная кривая взята из проверенного Excel, срез **31.07.2026, 18:49:59**. Доступны 23 расчётных срока, включая дополнительные сроки экстраполяции.
- Другие даты показывают отсутствие данных; незаметной подстановки другой даты нет.
- Расчёт выполняется локально с задержкой 1,2 секунды. Реальных запросов MOEX и подключения к БД нет.
- Внизу экрана раскрывается «Демонстрация состояний»: обычный расчёт, ошибка при ближайшем запуске, отсутствие исходных данных. После одной искусственной ошибки повторный запуск успешен.
- При смене даты или демонстрационного режима текущий расчёт отменяется, прошлый результат убирается.

## Реализованные возможности

1. Выбор отчётной даты и получение базовой кривой через заменяемый адаптер.
2. Изменение P/K/D по кнопке с карандашом. Стандартные параметры — 4/5/3 п.п. Допустимы конечные числа строго больше нуля и не больше 50 п. п. включительно; дробные значения поддерживаются. Отмена и Escape не сохраняют черновик.
3. Автоматическое получение базовой и расчёт шести стрессовых кривых со стандартными P/K/D при открытии экрана и выборе даты с доступными данными. При смене даты параметры возвращаются к стандартным. Кнопка «Пересчитать кривые» запускает повторный расчёт, в том числе с изменёнными параметрами. Редактирование параметров само по себе не пересчитывает результат; подпись и CSV используют параметры именно готового результата.
4. Состояния: данные доступны, выполнение, готовый расчёт, ошибка/повторная попытка и отсутствие данных. Повторный запуск заблокирован во время выполнения.
5. Выбор линий графика нажимаемыми блоками без галочек. Изначально выбрана только базовая кривая; каждую линию можно отключить, включая базовую. При пустом выборе показана подсказка. Выбор сохраняется между вкладками, масштаб Y фиксирован по полному текущему расчёту. Таблица содержит полный комплект; переключение линий не запускает расчёт.
6. Подсказки со сроком и ставками при наведении и фокусе. В графике работают стрелки, Home/End и Escape. Вкладки «График/Таблица» переключаются мышью или стрелками/Home/End.
7. CSV всего комплекта: семь кривых независимо от выбранных линий, дата, сценарий, бакет, тенор, ставка, P/K/D. UTF-8 BOM, разделитель `;`, десятичная запятая, экранирование кавычек и переносов. Выгрузка доступна только для полного готового результата. Окончательный формат согласуется.
8. Адаптивная компоновка; график и широкая таблица прокручиваются внутри блока. Подписи графика не уменьшаются до нечитаемого размера на мобильном экране.

Ставки выражены в процентах годовых, P/K/D — в процентных пунктах. При сложении параметры не делятся на 100.

## Структура

- `api` — интерфейс адаптера, демонстрационные данные и точка выбора реализации.
- `hooks` — получение данных, запуск/отмена расчёта и демонстрационные настройки.
- `store` — контекст внедрения адаптера.
- `components` — хедер, параметры/модальное окно, результаты и общий Button.
- `utils` — модели приложения, формулы IRRBB, форматирование и CSV.
- `assets/styles` — общая система стилей из Figma; `App.css` — основной экран по последнему HTML-прототипу.

## Проверка интерфейса

Проверены ширины 320, 390, 560 и 1366 px; отсутствие горизонтального переполнения страницы и прокрутка содержимого графика/таблицы. Проверен сценарий дата → автоматический расчёт → параметры → перерасчёт → сравнение → таблица → CSV, смена даты во время расчёта, ошибка/повторный запуск, отмена редактирования.

В модальном окне фокус начинается с P, Tab/Shift+Tab остаются внутри; Escape, отмена и применение возвращают фокус на карандаш. Страница 404 не реализована и остаётся отдельной задачей.

## Регрессионные проверки

`npm test` проверяет формулы и единицы, дробные/некорректные параметры, независимость результата от входных объектов, полноту семи кривых, сетку сроков, даты, CSV и отмену демонстрационного расчёта. Тесты используют встроенный Node.js test runner и установленный TypeScript, без дополнительных библиотек. Неполные ответы адаптера и результаты за другую дату/с другими параметрами отклоняются до отображения и выгрузки.

При запущенном `npm run dev` откройте `/tests/browser/`: отдельная проверка жизненного цикла React проверяет автоматический запуск в StrictMode, защиту от повторного запуска, смену даты и поздние ответы, стандартные и пользовательские параметры, отклонение неполных результатов, повтор после ошибки и размонтирование. Используется управляемый тестовый адаптер, намеренно возвращающий ответы даже после отмены. Тестовая страница не входит в production-сборку.

## Обновление исходных данных и точность параметров

Кнопка «Проверить наличие данных» повторяет запрос выбранной даты через адаптер. Она доступна и при отсутствии данных, и после готового расчёта, блокируется на время получения данных. Это не команда загрузки MOEX.

Сравнение исходной кривой выполняется по дате, бакетам, тенорам и точным базовым ставкам. Новые объекты с теми же значениями не пересчитываются. Обновлённая кривая скрывает прежний результат и запускает стандартный расчёт; запоздалые ответы игнорируются. Результат с другой базовой кривой отклоняется. Метаданные времени публикации сами по себе перерасчёт не запускают.

P/K/D отображаются отдельно от округлённых ставок: `0.001` показывается как `0,001`, очень малые значения могут использовать научную запись. Числа в расчётах и CSV не округляются.

При запущенном Vite откройте `/tests/browser/app.html` для интеграционных проверок настоящего App с Query, управляемыми ответами адаптера, полем даты, модальным окном, фильтрами, таблицей и формируемым CSV. Запросы завершаются явно, без произвольных задержек; настоящая сеть и загрузка файлов не используются. Проверки хуков по `/tests/browser/` сохранены. Обе тестовые страницы исключены из production entry point.

Точная проверка базовых ставок соответствует демонстрации. Точность реального серверного результата и разделение получения готового расчёта/ручного перерасчёта нужно сопоставить с фактическим HTTP-контрактом; произвольная погрешность и новые ручки не вводились.

## SVG-макеты главной страницы и окна параметров

Главная страница следует актуальному `главная.svg` 1440 × 1024, график — `curves.svg` 1381 × 509, окно — `change parametres.svg` 542 × 555. Панель параметров находится на x=27, y=267 (1382 × 121), результаты — x=27, y=412 (ширина 1384), шапка таблицы начинается на y=517. Высота блока результатов фиксирована: 509 px. Все 23 срока доступны во внутренней прокрутке таблицы; демонстрационные повторы из рисунка не используются. Ошибка расчёта расположена по центру белого блока.

Окно центрируется относительно видимой области, затемняет фон, удерживает клавиатурный фокус и возвращает его на карандаш. Подпись D исправлена на «Долгосрочный шок». Пользовательские тексты кнопок «Отмена» и «Применить» сохранены. Ошибки полей занимают предусмотренные промежутки и не меняют размеры окна, положение полей и кнопок; на небольшом экране окно прокручивается.

Кнопки выбора под графиком используют `aria-pressed`; голубой блок обозначает выбранную линию. Их порядок, цвета и штрихи взяты из нового SVG. Наведение/фокус показывает ставки включённых линий, стрелки переключают сроки. Масштаб рассчитывается по полному результату, включая выключенные линии. CSV всегда содержит семь кривых и параметры готового результата; пояснение формата доступно у кнопки скачивания.

Текст SVG переведён в контуры: использованы локальная Geologica и визуальная сверка; точные имена исходных Figma-текстовых стилей из контуров не извлекаются. График рисуется по данным приложения. Отличия содержимого от SVG преднамеренны: реальные сроки, правильные направления шоков, изначально только одна выбранная линия, полная таблица вместо повторяющихся строк.

Проверены 1440, 1366, 390 и 320 px, отсутствие горизонтального переполнения страницы, внутренняя прокрутка таблицы/графика, модальное окно с ошибками, Escape и цикл фокуса. Интеграционная страница `/tests/browser/app.html` дополнена проверками первоначального выбора, нескольких линий, отключения базы/всех линий, постоянного масштаба и сохранения выбора без расчёта. Проверки расчётных функций и жизненного цикла сохранены.

Выбор кривых по умолчанию развёрнут только под графиком. В таблице выбора и шеврона нет. Шеврон скрывает только выбор: линии и результат сохраняются, высота блока остаётся 509 px. Освободившееся место получает график. Таблица использует доступную область целиком. Размер графика отслеживается через ResizeObserver без нового расчёта.
