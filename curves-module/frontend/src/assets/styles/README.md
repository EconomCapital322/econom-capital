# Основа UI

Источник: [UI страницы «практика»](https://www.figma.com/design/GfedSzw069rs9JBLsHTR9t/PROJECTS?node-id=3263-9460).
Сверено 17.10.2026. Основной экран реализован по последнему HTML-прототипу; общие UI-токены сохранены.

## Подключение и структура

`src/main.tsx` подключает `src/index.css`, который импортирует:

- `fonts.css` — локальные Geologica 400, 500, 600, 700 из `src/assets/fonts`.
- `tokens.css` — значения из Figma.
- `base.css` — сброс шаблонных стилей Vite и общие настройки.
- `typography.css` — классы текстовых стилей; h1/h2/h3 используют соответствующие стили.
- `ui.css` — кнопки, плашки, поверхность и свечение фона.

Существующие папки api, components, hooks, pages, store, utils сохранены.
Bootstrap подключается первым в `main.tsx`; глобальные и компонентные стили переопределяют его значения под проект. Используются его кнопки, формы, вкладки, таблица, индикатор и структура модального окна.

## Компонентные стили

- `.button` — заливка #1EAFF7, белый текст 20/500, padding 10px 36px, radius 30px.
- `.button.button--outlined` — белый фон, текст и обводка 2px #1EAFF7; тот же padding. Обводка увеличивает наружный размер, как в Figma.
- `.chip` — 85×30px, padding 4px 25px, radius 20px, фон #F4F4F4, текст #848891, 16/400.
- `.chip.chip--selected` или `.chip[aria-pressed="true"]` — фон #1EAFF7, белый текст.
- `.chip.chip--neutral` — фон #F5F5F5, текст #35373A.
- `.surface` — белая поверхность, radius 20px.
- `.background-glow` — точная внутренняя тень фона: inset 0 2px 250px rgba(0,180,251,.2).

Варианты кнопки и плашки не объявлены состояниями hover/disabled: макет этого не определяет.
Глобальные стили не отключают штатный фокус браузера.
Инпуты наследуют шрифт и цвет; форма полей основного экрана задана по HTML-прототипу в `App.css`.

## Значения вне исходного UI-набора

- Инпуты: размер, padding, border, radius, placeholder, focus/error/disabled.
- Поведение и визуальные состояния hover, pressed, focus, disabled для кнопок.
- Семантический общий цвет border: обводка палитры чёрная служебная; обводка кнопки голубая, общего токена в UI нет.
- Сетка и responsive-правила будущих страниц, произвольная шкала отступов.

В UI-наборе эти свойства не определены. Для основного экрана соответствующие стили взяты из последнего HTML-прототипа и описаны отдельно в `App.css`. Общие токены Figma не изменены.
